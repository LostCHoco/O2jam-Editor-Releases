# O2jam-Editor Releases

This repository hosts signed Windows x86_64 portable releases for O2jam-Editor. The application source is maintained separately in a private repository.

## Latest stable

[O2jam-Editor 0.1.3](https://github.com/LostCHoco/O2jam-Editor-Releases/releases/tag/v0.1.3-stable.20261125.1)

## Choosing a release

Use the latest non-prerelease release for regular use. Prereleases are transitional builds and should normally arrive through the signed in-app updater; follow a prerelease's notes if they describe a specific migration.

The app checks signed updates automatically. User charts and data are kept outside the managed application files.
